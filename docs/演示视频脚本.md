## 1. 问题与定位（0:25—0:55）

**画面**：三行要点逐条出现。

**旁白**：

> 现有工具解决不了三个问题。
> 第一，聚合工具只把新闻**堆在一起**，不告诉你哪些其实是同一个事件。
> 第二，所谓"多家报道"经常是假的——同一个出版集团旗下的多个站点会互相转载，
> 按站点数统计会把**一家机构**的报道算成五家印证。
> 第三，AI 摘要读起来通顺，但你**没法核对**哪一句来自哪一篇原文。
>
> 我们做的是一个**多源新闻聚合与可溯源简报智能体**：
> 事件级归并、可信度可量化、每一句都可回溯到原文。

逐层高亮：采集 → 聚类 → 评分 → 生成 → **校验**。

### 3.2 事件聚类效果（1:45—2:15）

**操作**：


> ⚠️ `events` 现在**默认只看最近 24 小时**（`--hours` 默认 24）。

**旁白**：
> 这是按"印证机构数"排序的热点事件。

### 3.3 可解释的评分（2:15—2:35）

**操作**：
```bash

```
**旁白**：
> 每个事件的可信度都能展开看依据。
> 评分是三项相乘：来源权威性、时效衰减、交叉印证度。
> 关键在最后一项——**按机构而不是按站点计数，单一机构最高只能拿到 0.6**。

### 3.4 生成 + 校验（2:35—2:55）

**操作**（先用 `ready` 挑一条**材料充足**的事件——它会按材料字数排序，
并把可复制的 `brief` 命令连同 event_id 一起打出来）：
```bash
python -m src.cli ready --min-orgs 2 --top 5
python -m src.cli brief evt_xxxxxxxx      # 直接复制 ready 打印的那一行
```

> `ready` 的输出里还有一列「缺正文」：显示 0 表示这条事件各篇都抓到了正文，
> 录演示优先选它 —— 材料不足会走抽取式兜底，简报会短很多。
**旁白**：
> 生成简报。模型被要求输出结构化结果，**每一句事实都必须标注它在材料中的编号**。
> 然后我们的校验器会逐句回溯原文。
> 看最后这一段——事实一致性校验：**通过**，带依据句达到阈值（默认 80%），长度合规。
>
> ⚠️ **旁白要按屏幕实际数字念**（例如「逐句溯源 8/9 句达标、89%」），
> 不要预先背死「100%」—— 模型带采样（temperature 0.3），每次数字会略有不同；
> 若屏幕显示 89% 而旁白说 100%，评委会立刻发现对不上。
> 如果校验不通过，系统会自动降级成抽取式摘要：
> **宁可给出不好看但完全忠实原文的简报，也不输出可能失真的生成内容。**

**画面**：特写"事实一致性校验：通过"那一行。

## 4. 关键算法亮点（3:25—4:15）

**画面**：三条并排，左边"原假设"，右边"实测结论"。

**旁白**：

> 这个项目最有意思的地方，是几个**被测量推翻的假设**。
>
> 第一件：我们一开始想用标题的 SimHash 找出同一事件。
> 在最初那批 933 篇语料上实测，海明距离小于 3 的重复对一共 119 对——
> **全部是同一机构内部互转**，跨机构一对都没有；放宽到 10 也还是零。
> 原因是不同媒体对同一事件会写不同标题。
> 所以我们补了一层**语义近似**：IDF 加权余弦相似度，
> 阈值用人工样例标定——同事件 0.46 到 0.80，不同事件 0 到 0.23，取 0.5。
>
> 第二件：最初的结果显示多个事件都是"5 家源印证"。
> 逐条核对来源后发现，Army Times、Navy Times、Air Force Times、Military Times、
> Defense News 这些站点**同属一家出版集团**。
> 按站点算是 5，按机构算其实是 **1**。
> 修正之后，真正的多机构印证事件从虚高的 45 降到 2——这才是真实情况。
>
> 第三件是事件关键词。第一版是"把标题切 2 到 4 字再拼回去"，
> 抽出来的是"务院联""控机""习近"这种碎片——一句"不代表事件特点"就把它否了。
> 我们换成**无词典新词发现**：用互信息算内聚度、用左右邻接熵算自由度，
> 再加一条"最大 n-gram"规则。这条规则的由来很典型：
> 子串的内聚度可能比整词还高——"务院"4.73 反而高于"国务院"4.26，
> 所以光靠互信息必然切出碎片，必须补结构性规则。
> 现在候选只有两种：**词表里的词**，和**语料里反复出现的相邻词对**。
> 标定结果是好词命中 33/34、残渣 0/23。

**画面**：可以打出三个对比：`5 → 1`、`45 → 2`、`务院联 → 洛克希德马丁`。

> ⚠️ 数字口径：933 篇 / 119 对 / 45→2 是**最初那批语料**上的实测结果，
> 旁白要说"在最初那批 933 篇语料上"，不要说"现在"。库现在是三千多篇，
> 直接重跑这些数字会变，说清口径就不怕较真。
