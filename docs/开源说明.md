# 开源说明与合规声明

本文档说明 AIC-NewsBrief 的开源许可、第三方依赖、数据来源合规性、
可复现步骤与提交前匿名化要求。

---

## 一、许可证

本项目采用 **MIT License**，全文见仓库根目录 `LICENSE`。

**为什么选 MIT**：约束最少、最利于复用与二次开发，评审和他人复现时没有任何
额外义务门槛。如果希望额外包含专利授权条款，可换成 Apache-2.0 —— 只需替换
`LICENSE` 文件内容并在本文件与 `README.md` 中同步修改许可证名称。

`LICENSE` 中的著作权人写作 `AIC-NewsBrief contributors`。
**注意**：大赛要求匿名评审（见第四节），如需在公开仓库托管，请自行判断
是否要改成个人或组织名义。

## 二、第三方依赖

本项目刻意保持极少的依赖，核心算法全部自研。**唯一引入的第三方模型**是开源模型
**Qwen2.5-3B-Instruct 权重**（Apache-2.0），仅承担「把材料写成简报」这一步；
自研边界见第 2.1 节。

| 依赖 | 版本要求 | 许可证 | 用途 |
|---|---|---|---|
| `requests` | >= 2.31.0 | Apache-2.0 | HTTP 抓取 |
| `PyYAML` | >= 6.0 | MIT | 读取 `config/sources.yaml` 与 `config/orgs.yaml` |

> **完整的运行期依赖**（含模型推理与 Web 界面所需的 `torch` / `transformers` /
> `accelerate` / `bitsandbytes` / `gradio`，及其版本与许可证）见仓库根目录的
> `requirements.txt`，以及《开源及第三方资源使用清单》第二节。
> 上表只列**核心流水线**的依赖 —— 只用这两个库就能完成采集、聚类与评分；
> 需要生成简报或打开界面时，才需要 `requirements.txt` 中的第 ② ③ 组依赖。

**自行实现、未引入第三方库的部分**（这是本作品"技术实现"得分的主要来源）：

| 模块 | 功能 | 说明 |
|---|---|---|
| `src/parsers.py` | RSS 2.0 / Atom 1.0 / RDF 解析 | 纯标准库，含正则兜底解析，未使用 `feedparser` |
| `src/parsers_html.py` | 通用 HTML 列表页抽取 | 纯标准库 `html.parser`，**不写死任何站点选择器** |
| `src/dedup.py` | URL 归一化 + 64 位 SimHash | 纯标准库，未使用 `simhash` 等库 |
| `src/similarity.py` | IDF 加权 TF-IDF 向量 + 余弦相似度 | 纯标准库，未使用 `scikit-learn` |
| `src/cluster.py` | 分段桶剪枝 + 并查集事件聚类 | 自研 |
| `src/credibility.py` | 权威性×时效性×交叉印证度评分模型 | 自研 |

**未使用的常见依赖及原因**：`feedparser`（自研解析器更可控、少一个环境依赖）、
`jieba`（中文 2/3-gram 已足够且能覆盖未登录词，见 `src/similarity.py` 注释）、
`beautifulsoup4`/`lxml`（`html.parser` 足够，且避免编译依赖）、
`scikit-learn` / `sentence-transformers`（语义聚类用自研 IDF 加权 TF-IDF，见 `src/similarity.py`）。

### 2.1 引入的开源模型及其许可义务

**Qwen2.5-3B-Instruct** 是本项目**唯一**引入的第三方模型权重：

| 项 | 内容 |
|---|---|
| 许可证 | **Apache-2.0**（可商用、可再分发；需保留许可与版权声明） |
| 用途 | 简报生成（标题 / 价值点 / 正文）与跟语言材料归一化 |
| 使用方式 | **仅推理**，权重**未修改、未微调**；推理时做 **4-bit NF4 量化**（不改变权重内容） |
| 获取渠道 | 魔搭 ModelScope（`Qwen/Qwen2.5-3B-Instruct`），下载后逐一做 SHA256 校验 |
| 分发 | 权重**不随本仓库分发**（体积超限且无必要），由使用者按文档自行下载 |

**自研边界**（这是本赛道评分关注的重点）：

- 采集、解析、去重、聚类、可信度打分、事实一致性校验、结构化输出协议 **全部自研**；
- 开源模型只做「把已确定的材料改写成中文简报」这一步；
- 因此**当模型输出不合格时，系统会自动降级为抽取式摘要** ——
  最终产物不依赖模型「自由发挥」。

## 三、数据来源与合规声明

### 3.1 采集方式

- 仅采集各媒体**公开发布**的内容，通过**官方 RSS/Atom 订阅**或**公开列表页**获取。
- 优先使用 RSS；不使用任何绕过访问控制的手段，不破解、不伪造身份、不规避反爬。
- 源之间**串行**采集并设置间隔（默认 0.6 秒），避免对源站造成压力。
- 支持 `ETag` / `Last-Modified` **条件请求**：内容未更新时服务端返回 304，
  本项目直接跳过解析，进一步降低源站负担与自身流量。

### 3.2 内容使用

- 原文**仅本地存档**，用于生成摘要与事件聚合，**本项目不分发原文**。
- 因此 `data/` 与 `logs/` 已写入 `.gitignore`，**不进入版本库**。
- 生成结果（简报）中每一条信息均标注来源媒体、发布时间与原文链接，
  使用者可回跳原文核对。

### 3.3 内容定位（重要）

本项目的输出**严格限定**为对公开已发布原文的**聚合、复述与摘要**：

- 不做事件研判、不推测动机与意图、不做立场性表述；
- 不生成任何未经公开报道支持的内容；
- 单一机构来源的信息会被明确标记为「单一机构·待核实」。

代码与配置中**不包含任何非公开信息**，也不需要任何付费或授权数据源。

## 四、匿名化要求（提交前必做）

《全球校园人工智能算法精英大赛章程》第四十四条要求：

> 参赛材料提交规范。参赛团队提交作品时，须同步提交"承诺书"。
> **匿名版作品中严禁出现参赛人员姓名、指导教师姓名、参赛学校等任何可识别身份信息**，
> 保障评审环节的公平公正。

本项目提供一个自查脚本：

```bash
# 1) 复制模板并填入需要自查的姓名/学校/学号等（该文件已被 .gitignore 忽略，不会提交）
copy config\anonymize_watchlist.txt.example config\anonymize_watchlist.txt
# 编辑 config/anonymize_watchlist.txt，逐行写入姓名、学校、导师等

# 2) 运行扫描
python scripts/check_anonymize.py
```

脚本会扫描源码、配置与文档，报告：

- 命中自查清单的**任何身份信息**；
- 形如 `C:\Users\<用户名>`、`/home/<用户名>` 的**本机绝对路径**；
- 邮箱、手机号、QQ/微信号、学号等**模式化隐私信息**。

返回码非 0 表示存在问题，需清理后再提交。

**另需注意**：匿名版材料中不要出现学校实验室内网地址、个人 Git 仓库地址、
带真实姓名的截图或演示视频水印。

## 四之二、不应进入版本库的第三方材料

除新闻原文（见第三节）外，**主办方的赛题通知与规则附件同样是第三方作品**：

- 位置：`docs/rules/`（包含《关于举办第八届……的通知》与两份规则 PDF 及其抽取文本）
- 权利状态：著作权属大赛组委会；团队**无权公开与再分发**
- 处理方式：已写入 `.gitignore`，**仅本地留存用于开发对照，不进入版本库**
- 依据：《AIC·AI+开源竞赛规则及作品提交要求》第三条（六）
  「开放成果仅限团队依法有权公开和再分发的内容」

因此在公开仓库中，本项目的规则依据只以**文字引用**形式出现（注明条款编号），
不附原件。他人如需核对，可自行从大赛官网获取。

## 五、可复现步骤

评审或第三方复现本项目的完整流程：

```bash
# 0) 环境：Python 3.10+（开发环境为 3.10.21）
python --version

# 1) 安装依赖（仅两个）
pip install -r requirements.txt

# 2) 初始化数据库
python -m src.cli init

# 3) 源可用性体检（不写库，纯只读，可先跑这一步确认网络连通性）
python -m src.cli health

# 4) 跑完整流水线：采集 -> 事件聚类 -> 可信度打分
python -m src.cli pipeline

# 5) 下载开源模型权重（约 5.75 GB，首次必须；支持断点续传 + 自动 SHA256 校验）
python scripts/fast_download.py --model Qwen/Qwen2.5-3B-Instruct \
    --dir models/Qwen2.5-3B-Instruct
python scripts/check_model_file.py --file model-00001-of-00002.safetensors
python scripts/check_model_file.py --file model-00002-of-00002.safetensors

# 6) 生成简报（跨语言材料会先归一化为中文，结果缓存复用）
python -m src.cli normalize          # 可选：预热归一化缓存，避免首次生成时等待
python -m src.cli brief              # 对排名第一的事件生成简报
python -m src.cli daily --limit 5    # 批量生成并核对校验通过率

# 7) 启动 Web 界面（默认 http://127.0.0.1:7860）
python -m src.app

# 8) 查看结果
python -m src.cli stats
python -m src.cli events --min-orgs 2
python -m src.cli list --hours 24 --limit 30
```

**复现注意事项**

- 数据源为公开网络资源，需要能访问对应站点。实测部分境外站点
  （BBC / DW / Reuters / Al Jazeera / Janes 等）在本机网络环境下连接超时，
  已在 `config/sources.yaml` 中标记为 `enabled: false` 并注明原因；
  更换网络环境后可用 `python -m src.cli health --all` 重新评估。
- 采集结果随时间变化，因此**统计数字会随运行时间不同**。
  所有实测数值（含日期）均记录在 `docs/技术报告.md`，便于对照。
- 算法阈值的标定过程有可复现脚本：
  - `scripts/evaluate_similarity.py` —— 语义相似度阈值标定
  - `scripts/analyze_orgs.py` —— 交叉印证构成分析
  - `scripts/dump_context.py` —— 网页结构探查
  - `scripts/probe_feeds.py` —— 候选源批量探查
