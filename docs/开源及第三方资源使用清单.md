## 一、开源模型（核心 AI 能力）

| 项 | 内容 |
|---|---|
| 资源名称及类型 | **Qwen2.5-3B-Instruct**（开源大语言模型权重） |
| 版本 / 来源 | 版本 `master`（2026-09 拉取）；来源：**魔搭 ModelScope**（`Qwen/Qwen2.5-3B-Instruct`）；SHA256 随文件清单逐文件校验 |
| 许可证 / 授权类型 | **Apache-2.0**（仓库内含 `LICENSE` 文件，已随权重一并留存） |
| 使用方式 | 作为本作品的**摘要生成引擎**：接收"多来源材料 + 结构化输出要求"的提示词，产出短标题、价值点与约 300 字简报。**本地部署推理**（4-bit NF4 量化），不联网调用第三方服务 |
| 关键许可义务 / 限制 | Apache-2.0 要求：保留版权与许可声明；如分发修改后的作品需注明修改。**本作品未修改模型权重**，仅按原样加载推理，不使用其训练/微调 |
| 自主开发边界 | **模型权重为第三方成果**；提示词工程、结构化输出协议、事实一致性校验、事件聚类、可信度评分均为团队自主开发（见第四节） |
| 合规状态 | ✅ 已遵守。权重不入版本库（`models/` 已 `.gitignore`），由使用者按官方渠道自行获取，避免再分发义务与体积问题 |
| 开放方式 | 不随仓库分发权重；提供 `scripts/fast_download.py` 一键获取脚本（含 SHA256 校验） |

**说明**：选型理由见技术报告第三节。3B 的 bf16 权重约 5.8 GB，直接放入 8 GB 显存
余量不足，因此采用 **4-bit（NF4）量化**（**实测 1.92 GB**）；加载器在量化不可用时
**自动回退全精度**，保证可移植性。符合赛题"不要求训练大规模模型、
不要求采购专用硬件"的定位。

### 2.1 明确**未使用**的常见依赖及原因

这一点同样重要 —— 说明"哪些不是拿来的"：

| 未使用的库 | 常被用于 | 本作品为何不用 |
|---|---|---|
| `feedparser` | RSS/Atom 解析 | 自研 `src/parsers.py`（纯标准库 + 正则兜底），可控性更好、少一个环境依赖 |
| `beautifulsoup4` / `lxml` | HTML 解析 | 自研 `src/parsers_html.py`（纯标准库 `html.parser`），避免编译型依赖 |
| `simhash` | 近似重复检测 | 自研 `src/dedup.py` 的 64 位 SimHash 实现 |
| `scikit-learn` | 向量化与相似度 | 自研 `src/similarity.py` 的 IDF 加权 TF-IDF + 余弦 |
| `jieba` | 中文分词 | 自研字符 2/3-gram 方案，能覆盖未登录词（人名、装备型号）且无需词典 |
| 任何**在线通用大模型 API** | 摘要生成 | 默认后端为**本地开源模型权重**，可完全离线；在线通道仅为可选备份（见第三节） |

## 四、自主开发边界（团队原创部分）

**以下模块全部为团队自主设计、编码、调试与验证，未基于任何第三方同类实现：**

| 模块 | 自主实现内容 | 性质 |
|---|---|---|
| `src/parsers.py` | RSS 2.0 / Atom 1.0 / RDF 解析器，含编码嗅探与正则兜底 | 原创实现 |
| `src/parsers_html.py` | 通用 HTML 列表页抽取：容器归集 + 日期向后携带，**不写死站点选择器** | 原创算法 |
| `src/dedup.py` | URL 归一化 + 64 位 SimHash + 海明距离 | 原创实现 |
| `src/similarity.py` | IDF 加权 TF-IDF 向量 + 余弦相似度（语料内自估 IDF） | 原创实现 |
| `src/cluster.py` | **分段桶剪枝** + 并查集三阶段事件聚类（内容指纹 → SimHash → 语义） | 原创算法 |
| `src/credibility.py` | 可信度评分模型 `100×f_tier×f_time×f_cross`，按**机构**去重计数 | 原创模型 |
| `src/verify.py` | **事实一致性校验**：加权关键词覆盖率溯源 + 推测性表述检测 + 自动降级 | 原创机制 |
| `src/brief.py` | 结构化简报协议（带 `claims` 句级依据的 JSON）与提示词设计 | 原创设计 |
| `src/collect.py` / `store.py` / `fetch.py` / `cli.py` | 采集编排、增量去重、SQLite 存储与幂等迁移、条件请求 | 原创实现 |
| `config/*.yaml` | 源配置（逐条实测标注）、机构映射、模型后端配置 | 原创 |

**AI 工具辅助说明**：本项目开发过程中使用了生成式 AI 编码助手（GitHub Copilot）
辅助编写代码与文档。团队对全部纳入作品的代码逐文件复核、运行验证与修改，
所有算法阈值均由团队编写标定脚本实测确定（见 `scripts/evaluate_similarity.py`
等）。详见技术报告"团队分工与过程记录"一节。

## 五、数据来源（**重要：公开可访问 ≠ 开源**）

赛题规则明确："不得将仅因'公开可访问'而缺乏明确再利用授权的资源当然视为开源资源"、
"公开可访问不等同于当然取得复制、训练、改编或再分发授权"。本作品的处理原则如下：

| 项 | 内容 |
|---|---|
| 数据名称及类型 | 各媒体**公开发布的新闻内容**（含标题、摘要、正文）——**非开源数据** |
| 来源 | 官方媒体与主流媒体的公开 **RSS/Atom 订阅**及公开列表页，共 29 个源（配置见 `config/sources.yaml`，每源均标注实测日期与启用理由） |
| 获取方式 | 仅 HTTP GET 公开接口；遵守 `robots.txt` 与服务条款；**不绕过任何访问控制**；源间串行并设间隔；支持 `ETag`/`Last-Modified` 条件请求降低源站负担 |
| 授权状态 | 原文著作权归原媒体所有。本作品**不主张对原文的任何权利** |
| 使用方式与边界 | **仅本地存档**用于生成摘要与事件聚合；`data/`、`logs/` 已 `.gitignore`，**不进入版本库、不向第三方再分发原文** |
| 输出合规 | 生成结果中每一条信息均标注来源媒体与原文链接，使用者可回跳原文核对 |
| 合规状态 | ✅ 未再分发、未用于训练模型、未声称对原文的权利 |
| 开放方式 | **开放代码，不开放数据**。他人复现时由各自环境按公开源自行采集 |

**模型训练数据**：本作品**未使用上述新闻数据训练或微调任何模型**，
模型权重完全使用官方发布的原版。
