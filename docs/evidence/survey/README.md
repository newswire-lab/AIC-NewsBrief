# 外部验证佐证材料（survey）

本目录存放**外部试用问卷**的原始材料，用于支撑评分表中
「问题场景（15 分）」与「实现完成度（25 分）」两处论证。

> ⚠️ 匿名要求：这里只放**匿名问卷数据**，不得出现受访者姓名、学校、联系方式；
> 现场照片避免拍到人脸与工位标识。提交前跑一次 `python scripts/check_anonymize.py`。

## 目录约定

| 文件 | 内容 |
|---|---|
| `raw_YYYYMMDD.xlsx` | 问卷平台导出的原始答卷（问卷星/腾讯问卷可直接导出） |
| `summary.md` | 汇总表 + 统计口径（模板见下） |
| `onsite_01.jpg` … | 现场试用记录（可选，1~2 张即可） |

## 写进技术报告

在 §5 新增一小节（或并入 5.4），建议措辞：

> **外部试用反馈（n=__）**
> 于 2026-10-__ 至 10-__ 通过现场试用与演示视频分发回收有效问卷 __ 份，
> 受访者均为未参与开发的第三方。__/__ 表示遇到过「同一事件多源说法不一致」的困扰；
> __/__ 认为「N 家独立机构印证 + 可信度评分」有用；__/__ 能理解证据链按机构去重的口径。
> 反馈暴露的主要问题是「____」，已（/计划）在 ____ 处改进。
> 原始问卷与汇总表见 `docs/evidence/survey/`。

## 三条纪律

1. **不伪造**：没有的数据不写；样本小就写明「小样本（n=6），结论仅供参考」。
2. **不引导**：问「哪里不好用」而不是「是不是很好用」；选项里必须有负向项。
3. **不留身份**：不收集姓名/学校；原始答卷里若含平台自动记录的 IP 等字段，导出时删掉。
