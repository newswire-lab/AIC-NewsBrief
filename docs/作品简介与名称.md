## 作品简介（定稿）

同一件事，不同媒体转来转去，说法常常对不上，读者也说不清有几家信源在讲。AI 摘要读着顺，你却不知道每句从哪来。

工具每天自动收集公开新闻，把讲同一件事的报道归到一起，再看被几家不同的机构报道过。算的是机构不是网站，同一家集团旗下几个站点只算一家。据此给每条信息一个可解释的可信度分数。

简报由本地开源模型 Qwen2.5-3B 生成，不用联网。模型每写一句都要标出依据来自哪篇原文，校验器逐句核对；核不过就退回原文摘录，宁可生硬，也不让没根据的话发出去。

实测单日收集三千五百余条，剪枝后只比对 2.65% 的组合。

代码以 MIT 开源，源配置、调参与合规文档一并公开，可离线复现。

## 字数校验（2026-10-28 复核）

⚠️ **两次踩过的坑**：

1. 2026-09-29：「去军事化」改写后正文变长，标注仍为旧值 287 字，
   实测汉字 304 / 不计空格 421，三种口径全部超限，已压缩改写。
2. 2026-10-28：上一版正文「不计空白 293 字」看似安全，但**换行符同样占字符**——
   该版按段落单换行排版实为 **304 字符**、按空行排版实为 **308 字符**，
   两者**都会被 300 字上限截断**（网页 textarea 的 maxlength 会直接砍掉结尾的「可离线复现。」）。
   本次已压缩改写，五种口径全部留出余量。

| 口径 | 现行 | 上限 | 判定 |
|---|---|---|---|
| 中文汉字 | 237 | 300 | ✅ |
| 汉字+标点 | 262 | 300 | ✅ |
| 不计空白字符 | 282 | 300 | ✅ |
| 全部字符（含段落间单换行） | 293 | 300 | ✅ |
| 全部字符（含段落间空行） | 297 | 300 | ✅ |

- 最严口径为「全部字符含空行」= 297 字，距上限仍有 3 字余量，
  因此无论表单按汉字、按标点、还是按 HTML `maxlength` 全字符计数，均不会被截断。
- 复算命令（退出码 0 = 合规，1 = 超限，可直接做提交门禁）：

```powershell
python scripts/check_brief_length.py            # 加 --verbose 可看逐行统计
```
